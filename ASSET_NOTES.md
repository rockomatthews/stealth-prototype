# Asset provenance

Original character concept sheets were generated with AI as modeling references. Step and shot WAV files were generated procedurally. Game source, map, materials and proxy geometry are included.

The user supplied Meshy-generated spy, merc and carbine models. Optimized character rigs, their Blender/FBX sources, textures and the carbine import are included. Raw high-poly character imports and downloads remain local. Modeling reference documents and PNGs were generated with AI. Verify applicable Meshy output rights for your own reuse; repository inclusion is not a separate asset license.

Epic mannequin meshes and animation clips imported from MoverExamples are excluded. The character rigs use the prototype mannequin skeleton, so recreate it and its animation clips locally with Scripts/migrate_mannequin.py using your Unreal installation, subject to Epic's applicable terms. Unreal Engine is not included. No third-party asset rights are granted by this repository.

This original stealth prototype is unaffiliated with Splinter Cell or Halo. No project-wide open-source license has been selected.
