# Asset provenance

Original character concept sheets were generated with AI as modeling references. Step and shot WAV files were generated procedurally for this prototype. Game source, map, materials and proxy geometry are included.

Epic mannequin meshes and animation clips imported from the installed MoverExamples plugin are excluded from this public repository. Recreate these locally with Scripts/migrate_mannequin.py using your Unreal installation, subject to Epic's applicable terms. Unreal Engine itself is not included. No third-party asset rights are granted by this repository.

This is an original asymmetric stealth prototype, unaffiliated with Splinter Cell or Halo. No project-wide open-source license has been selected.
